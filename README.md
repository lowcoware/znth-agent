# znth-agent

**Свой ИИ-агент: минимальное ядро, свой UX.**

znth-agent — мой собственный агент, который я собираю из актуального кода Hermes Agent: вырезаю всё лишнее, оставляю только то, чем реально пользуюсь, и перетаскиваю интерфейс (UX) из openclaude. Репозиторий ведётся как самостоятельный проект с чистой историей — это не GitHub-форк, а свой проект на основе открытого кода.

## Состояние

Базлайн собран, дальше — резка и UX:

- **P0 — сделано:** снимок актуального апстрима `NousResearch/hermes-agent` @ `ae3f9f9` (2026-10-13) залит первым коммитом.
- **P1 — в работе:** решения по объёму (какие платформы, провайдеры, инструменты и поверхности остаются) и согласование областей резки.

## Стек (унаследован от базлайна)

- **Ядро агента:** Python — цикл хода, провайдеры моделей, память, компрессия контекста, сборка промпта.
- **Гейтвей:** Python — платформы связи (Telegram, Discord, ещё ~19 адаптеров-плагинов), сессии, доставка.
- **TUI:** React + Ink (`ui-tui/`, свой форк Ink внутри репо) плюс Python JSON-RPC бэкенд (`tui_gateway/`).
- **Инструменты:** реестр с автообнаружением (`tools/`), наборы и ядро — `toolsets.py`.
- **Расширения:** плагины и скиллы; ядро сознательно узкое.

## Происхождение и лицензия

- Код основан на [Hermes Agent](https://github.com/NousResearch/hermes-agent) (Nous Research), лицензия **MIT** — файл [`LICENSE`](LICENSE) сохранён без изменений, авторство и условия соблюдены.
- UX-идеи, вёрстка и компоновка интерфейса — по мотивам [openclaude](https://github.com/Twigpine/openclaude). У самого openclaude лицензия непростая: он производный от проприетарного исходника Claude Code и распространяется под MIT «где это юридически допустимо». Поэтому из него переносятся **дизайн и поведение интерфейса**, а не код как есть.
- Файл `README.upstream.md` — это README апстрима на момент базлайна, сохранён для истории и сверки.
