# План резки: области-кандидаты

> Вердикты по областям и номерам — в `docs/DECISIONS.md`. Здесь только перечень кандидатов с числами.

Правило работы: **резать одну область за проход**, один проход = один коммит с числами в сообщении. Перед резкой каждая область согласуется владельцем: молчание по номеру = не режем. После каждого прохода — строгий импорт (`scripts/strict_import_check.py`) и запись в этот файл.

Числа — замер по снимку `ae3f9f9` (2026-10-13), файлы/строки/размер на диске.

## Не трогаем (каркас)

- `agent/` (347 файлов, 137 тыс. строк) — ядро агента: цикл хода, провайдеры, память, компрессия, сборка промпта.
- `hermes_cli/` (684 файла, 276 тыс. строк) — CLI, сетап, конфиг, скины, обновление. Режется внутри (подкоманды), не целиком.
- `gateway/` (188 файлов, 97 тыс. строк) — цикл гейтвея и общий транспорт платформ.
- `tools/` (357 файлов, 125 тыс. строк) — инструменты; резка идёт по файлам инструментов **и** по именам в `toolsets.py`.
- `toolsets.py` — `_HERMES_CORE_TOOLS` (59 имён) и `TOOLSETS` (37 наборов). Главный рычаг «легче и быстрее»: каждый инструмент уходит в модель на каждом вызове. Резать построчно по границам скобок, действующий набор подтверждать построением, а не чтением.
- `ui-tui/` (544 файла, 106 тыс. строк) + `tui_gateway/` (107 файлов, 44 тыс. строк) — TUI и его RPC-бэкенд; сюда же переносится UX из openclaude.
- `cron/`, `skills/`, `plugins/` — механизмы, режутся внутри.

## Хвосты апстрима, о которых помнить

- `agent/secret_sources/` удалять целиком нельзя: на нём держится общий код (`base.py`, `run_cli`) локального хранилища логинов и `agent/vault_backends/*`.
- `tools/browser_tool_cloud.py` — общие помощники конфигурации браузера живут там же, где облачный резолвер: удалять файл нельзя, можно заглушить резолвер.
- `tools/computer_use/` опирается на `tools/bot_desktop/`.
- `tools/connectors/` — это установщик плагинов/скиллов из каталога, а не коннекторы к сервисам.
- Импорты бывают ленивые (`try/except ImportError` внутри функции) — дерево соберётся после удаления и упадёт на вызове. Проверка — строгий импорт с печатью `__file__` и сверкой с корнем форка.
